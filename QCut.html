QCut API reference#

Cutting#

Marking cuts by hand, finding them automatically, and splitting the circuit.

cut()

Return a single qubit wire cut instruction.

cutGate(gate, control, target[, ...])

Return a CutGate circuit decomposing the input gate with QPD cut markers.

cutCZ()

Return a two qubit cutCZ gate instruction.

cutSWAP()

Return a two qubit cutSWAP gate instruction.

cutISWAP()

Return a two qubit cutISWAP gate instruction.

get_locations_and_subcircuits(circuit[, ...])

Get cut locations and subcircuits with placeholder operations.

find_cuts(circuit[, options])

Partition a quantum circuit into subcircuits by inserting cut operations.

consolidate_two_qubit_blocks(circuit[, ...])

Merge runs of gates acting on the same qubit pair into single unitaries.

Options#

CutOptions([consolidate, ...])

Configuration for a cutting run.

and DEFAULT_OPTIONS, used when none are given.

Transpilation#

transpile_subcircuits(cut_circuit, backend)

Transpile subcircuits for a given backend.

transpile_experiments(cut_experiment, backend)

Transpile experiment circuits.

transpile_circuits(circuits, backend[, ...])

Transpile for a backend, whatever stage the circuits have reached.

Primitives#

Several cut circuits in one call, and the jobs and results that call hands back.

CutEstimator(backend)

Expectation values of cut circuits, run on any backend or sampler.

CutQuasiSampler(backend)

Quasi-probability distributions of cut circuits, run on any backend or sampler.

primitives.CutEstimatorJob(jobs)

A CutEstimator run, whose result() is a CutEstimatorResult.

primitives.CutEstimatorResult(entries)

What a CutEstimator run gives back: one entry per input circuit.

primitives.CutEstimatorEntry(...)

The expectation values of one input circuit.

primitives.CutQuasiSamplerJob(jobs)

A CutQuasiSampler run.

primitives.CutQuasiSamplerResult(entries)

What a CutQuasiSampler run gives back: one entry per input circuit.

primitives.CutQuasiSamplerEntry(...)

The reconstructed distribution of one input circuit.

primitives.QCutPrimitiveJob(jobs)

A primitive's run, handed back as soon as everything is submitted.

primitives.CutRunEstimate(breakdown, ...)

What a primitive's run will cost, over every circuit and for each one.

Experiments and execution#

One cut circuit step by step: build its experiment, check the cost, submit it.

get_experiment_circuits(cut_circuit[, ...])

Generate experiment circuits by inserting QPD operations on measure/initialize/cutCZ nodes.

estimate_run(cut_experiment[, shots, ...])

Work out what submit_experiments() will cost, without submitting anything.

RunEstimate(breakdown, ...)

What running an experiment will cost, before anything is submitted.

JobEstimate(circuits, shots)

One run call: how many circuits it carries, at how many shots each.

submit_experiments(cut_experiment[, shots, ...])

Submit experiment circuits and return without waiting for their results.

run_experiments(cut_experiment[, shots, ...])

Run experiment circuits and wait for their results.

QCutJob(experiment, backend, shots, ...[, ...])

A submitted experiment, handed back before any of its results are in.

PartialBatch(index, wave, job_id, status, ...)

One run call of a submitted experiment, as it stands.

ParallelBackend(backends[, ...])

Spread an experiment's jobs over several backends, giving each batch to the least loaded.

run(circuit[, observables, backend, ...])

Run the whole circuit knitting sequence with one function call.

run_cut_circuit(cut_circuit[, observables, ...])

After splitting the circuit run the rest of the circuit knitting sequence.

and ObservablesLike, what observables can be given as.

Results and post-processing#

RawResult(results, shots[, experiment])

Simple wrapper class for raw experiment results.

CircuitResult(result, index, scale, ...)

One subcircuit's result within one group, before it is turned into counts.

estimate_expectation_values(results)

Calculate the estimated expectation values.

estimate_standard_errors(results)

An upper bound on the shot noise in estimate_expectation_values().

estimate_probabilities(result)

Reconstruct the distribution over the qubits the experiment measured.

QuasiProbabilities(data[, shots])

A reconstructed distribution over bitstrings.
