Estimator#

class QCut.CutEstimator(backend)[source]#

Bases: object

Expectation values of cut circuits, run on any backend or sampler.

Shaped like FiQCI-EMS’s estimator: made once for a backend, then run() with the cut circuits and the observables to estimate on them. A cut circuit comes from QCut.get_locations_and_subcircuits() or QCut.find_cuts(), and is run with the options it was made with.

The estimator does not transpile, much as qiskit’s primitives take circuits already written for their target. For a backend with a coupling map, transpile each cut circuit for that same backend with QCut.transpile_subcircuits() first.

Parameters:

backend – the backend or V2 sampler to run on. A sampler, like a backend without a coupling map, takes the circuits as they are.

Submit the circuits and return without waiting for their results.

Parameters:

  • circuits – a cut circuit or a list of them.

  • observables – what to estimate, taken as qiskit’s estimator takes them – a label, a Pauli, a SparsePauliOp, a SparseObservable, a {label: coefficient} mapping, or a nested sequence of those. One circuit takes them as given. With a list of circuits, give a list with one entry per circuit, or one observable for every circuit.

  • shots (int) – shots per experiment circuit, as in QCut.submit_experiments().

  • max_batch_size (int) – the most circuits submitted in one run call. Each input circuit is submitted in batches of its own.

  • parameter_values – {parameter or name: value} to bind into the circuit, paired with the circuits the way observables is. For a sweep, list the same circuit once per set of values.

  • **run_options – passed on to every run call on the backend.

Returns:

a handle on every circuit’s experiment, whose result() gives the expectation values.

Return type:

CutEstimatorJob

Raises:

  • QCutError – something other than a cut circuit was given, one is not transpiled for this backend although it has a coupling map, or one has parameters left unbound.

  • ValueError – the observables or parameter values do not have one entry per circuit, or the observables do not fit their circuit.

Sampler#

class QCut.CutQuasiSampler(backend)[source]#

Bases: object

Quasi-probability distributions of cut circuits, run on any backend or sampler.

Shaped like FiQCI-EMS’s sampler, but what comes back is reconstructed rather than counted: a quasi-probability distribution over the measured bits, which can dip below zero by the estimate’s noise. The qubits are the ones the circuit measured at its end before it was cut, and the bitstrings follow qiskit’s convention, classical bit zero rightmost.

A cut circuit comes from QCut.get_locations_and_subcircuits() or QCut.find_cuts(), and is run with the options it was made with. The sampler does not transpile: for a backend with a coupling map, transpile each cut circuit for that same backend with QCut.transpile_subcircuits() first.

Parameters:

backend – the backend or V2 sampler to run on. A sampler, like a backend without a coupling map, takes the circuits as they are.

run(circuits: CutCircuit | list[CutCircuit], shots: int = 4096, max_batch_size: int = 100, parameter_values: dict | list[dict] | None = None, **run_options) → CutQuasiSamplerJob[source]#

Submit the circuits and return without waiting for their results.

Parameters:

  • circuits – a cut circuit or a list of them, each split from a circuit that ended in the measurements whose distribution is wanted, measuring into every classical bit exactly once.

  • shots (int) – shots per experiment circuit, as in QCut.submit_experiments().

  • max_batch_size (int) – the most circuits submitted in one run call. Each input circuit is submitted in batches of its own.

  • parameter_values – {parameter or name: value} to bind into the circuit. With a list of circuits, a list with one entry per circuit, or one for every circuit. For a sweep, list the same circuit once per set of values.

  • **run_options – passed on to every run call on the backend.

Returns:

a handle on every circuit’s experiment, whose result() gives the distributions.

Return type:

CutQuasiSamplerJob

Raises:

  • QCutError – something other than a cut circuit was given, one is not transpiled for this backend although it has a coupling map, has parameters left unbound, or its final measurements do not fill its classical bits once each.

  • ValueError – the parameter values do not have one entry per circuit.

class QCut.primitives.QCutPrimitiveJob(jobs: list[QCutJob])[source]#

Bases: Generic[R]

A primitive’s run, handed back as soon as everything is submitted.

Shaped like a qiskit job. Each input circuit is one experiment with a QCutJob of its own, in jobs, and this answers for all of them together: the ids and statuses cover every circuit, and cancel() cancels every circuit.

result() waits for every circuit and builds the primitive’s own result, which is what the estimator and the sampler differ in. raw_results() gives the raw counts behind it.
